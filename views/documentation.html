Arsitektur Sistem & Pengantar

Dokumentasi API platform EcoPlan ini mencakup spesifikasi lengkap basis endpoint, format payload Request JSON, hingga struktur Response API untuk mendukung implementasi sistem secara penuh[cite: 5]. Base URL API backend: http://localhost:8080/api/v1.

Otentikasi & Keamanan (JWT)

Sistem menggunakan JSON Web Token (JWT) dengan header Authorization: Bearer <TOKEN>.

Authorization: Bearer <TOKEN_JWT_ANDA>

1. Manajemen Akun (Authentication)

POST /auth/register

Mendaftarkan akun baru (role: user atau seller).

Request Body (JSON)

{
  "name": "Nama Lengkap User",
  "email": "user@ecoplan.com",
  "password": "passworduser",
  "role": "user"
}

Response Body (201 Created)

{
  "success": true,
  "message": "Registrasi akun berhasil",
  "data": {
    "id": "c5a6b7c8-1234-5678-90ab-cdef12345678",
    "name": "Nama Lengkap User",
    "email": "user@ecoplan.com",
    "role": "user",
    "created_at": "2026-09-13T19:00:00Z"
  }
}
POST /auth/login

Otentikasi kredensial pengguna dan menerbitkan JWT token.

Request Body (JSON)

{
  "email": "user@ecoplan.com",
  "password": "passworduser"
}

Response Body (200 OK)

{
  "success": true,
  "message": "Login berhasil",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "user": {
      "id": "c5a6b7c8-1234-5678-90ab-cdef12345678",
      "name": "Nama Lengkap User",
      "email": "user@ecoplan.com",
      "role": "user"
    }
  }
}

2. Deteksi Sampah AI (Machine Learning)

POST /detections

Mengunggah citra sampah untuk diklasifikasikan via ResNet-50[cite: 5].

Content-Type: multipart/form-data (key: image)

Response Body (200 OK)

{
  "success": true,
  "message": "Deteksi sampah berhasil",
  "data": {
    "detection_id": "d1e2f3a4-5678-90ab-cdef-1234567890ab",
    "category": "plastic",
    "confidence": 0.942,
    "recommendation": "Bersihkan dan pisahkan ke wadah daur ulang plastik."
  }
}
GET /detections/history

Mengambil riwayat deteksi pengguna yang memerlukan token otentikasi.

Response Body (200 OK)

{
  "success": true,
  "data": [
    {
      "id": "d1e2f3a4-5678-90ab-cdef-1234567890ab",
      "category": "plastic",
      "confidence": 0.942,
      "image_url": "https://storage.ecoplan.com/images/sampah.jpg",
      "created_at": "2026-09-13T19:10:00Z"
    }
  ]
}

3. Edukasi & Gemini AI

GET /guides/:category

Mengambil panduan penanganan berdasarkan kategori sampah spesifik.

Response Body (200 OK)

{
  "success": true,
  "data": {
    "category": "plastic",
    "title": "Pengelolaan Sampah Plastik Rumah Tangga",
    "steps": [
      "Cuci bersih sisa makanan pada botol plastik.",
      "Lepaskan label dan tutup botol.",
      "Kumpulkan ke bank sampah terdekat."
    ]
  }
}
POST /guides/ai-suggestion

Memicu Gemini AI untuk saran daur ulang kustom.

Request Body (JSON)

{
  "category": "plastic",
  "prompt": "Bagaimana cara membuat pot tanaman gantung dari botol plastik?"
}

Response Body (200 OK)

{
  "success": true,
  "data": {
    "suggestion": "Potong bagian tengah botol plastik, buat lubang drainase di bawahnya, lalu pasang tali penggantung..."
  }
}

4. Artikel & Publikasi (Full CRUD + Admin Review)

POST /articles

Mengirim draf artikel baru lengkap dengan skor Turnitin[cite: 5].

Request Body (JSON)

{
  "title": "Strategi Pengolahan Sampah Plastik",
  "content": "Pengolahan sampah plastik memerlukan keterlibatan aktif...",
  "turnitin_score": 12.5
}

Response Body (201 Created)

{
  "success": true,
  "message": "Draf artikel berhasil dikirim",
  "data": {
    "id": "a1b2c3d4-0000-0000-0000-000000000000",
    "status": "pending_review"
  }
}
GET /articles

Menampilkan daftar artikel terpublikasi dengan parameter pencarian.

Response Body (200 OK)

{
  "success": true,
  "data": [
    {
      "id": "a1b2c3d4-0000-0000-0000-000000000000",
      "title": "Strategi Pengolahan Sampah Plastik",
      "author": "Shinta Nursobah Chairani",
      "status": "published"
    }
  ]
}
PUT /articles/:id

Memperbarui draf artikel oleh penulis.

Request Body (JSON)

{
  "title": "Revisi: Strategi Pengolahan Sampah Plastik",
  "content": "Konten artikel yang telah disempurnakan..."
}
PATCH /articles/:id/review

Moderasi dan persetujuan artikel oleh admin.

Request Body (JSON)

{
  "status": "published",
  "turnitin_score": 12.5
}
DELETE /articles/:id

Menghapus artikel dari sistem.

5. Marketplace, Toko & Produk (Full CRUD)

POST /stores

Pendaftaran toko baru dan pengaktifan role seller.

Request Body (JSON)

{
  "store_name": "Toko Daur Ulang Mandiri",
  "store_description": "Pusat kerajinan tangan dan kompos organik.",
  "address": "Sleman, Yogyakarta"
}
POST /marketplace/products

Menambahkan produk baru ke katalog toko.

Request Body (JSON)

{
  "name": "Pupuk Kompos Organik 5kg",
  "description": "Kompos murni hasil olahan sampah dapur.",
  "price": 25000,
  "stock": 100,
  "category": "biological"
}
GET /marketplace/products

Menampilkan daftar seluruh produk marketplace.

PUT /marketplace/products/:id

Memperbarui informasi produk marketplace.

Request Body (JSON)

{
  "name": "Pupuk Kompos Organik Super 5kg",
  "price": 28000,
  "stock": 85,
  "category": "biological"
}
DELETE /marketplace/products/:id

Menghapus produk dari marketplace.
